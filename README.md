# Sestante – Geoeconomic Intelligence Platform

**OpenIndustria TechLab** · a cura di Marco Pugliese · versione 2 · © 2026, tutti i diritti riservati

Sestante misura la reale capacità economica, industriale e strategica degli Stati e le loro vulnerabilità. Copre 195 Paesi con dati essenziali e le 42 maggiori economie (circa il 90% del PIL mondiale) con il modello completo: 16 indici sintetici, Power Index con pesi modificabili, scenari e Digital Twin, early warning, supply chain, materie prime critiche, rete geoeconomica, previsioni, report e la classifica proprietaria **Sestante Global 500** delle maggiori imprese del mondo.

## Pubblicazione su GitHub Pages

Carica nel repository tutti i file di questa cartella mantenendo la struttura (`index.html`, `LICENSE`, `README.md`, `THIRD_PARTY_NOTICES.md`, `.nojekyll`, `third_party/`). Poi apri *Settings → Pages*, scegli *Deploy from a branch*, ramo `main`, cartella `/ (root)`, e salva: dopo un paio di minuti il sito è online all'indirizzo `https://<utente>.github.io/<repository>/`. Per un dominio proprio (per esempio `sestante.openindustria.it`) inseriscilo in *Custom domain* e crea il record DNS indicato da GitHub.

L'analista IA funziona solo all'interno di Claude; sul sito GitHub la pagina lo segnala e tutte le altre funzioni restano attive. Le impostazioni dell'utente (pesi, dashboard, dati importati) si salvano nel suo browser.
